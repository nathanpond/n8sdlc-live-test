# Security Policy

## Reporting a vulnerability

Please report vulnerabilities through
[private vulnerability reporting](https://github.com/nathanpond/n8sdlc-live-test/security/advisories/new)
— **never through a public issue**. A public reproduction is a working exploit
handed to everyone before a fix exists.

This is a personal project maintained on a best-effort basis: reports are read
and taken seriously, but there are no committed response timelines.

## Security findings register

Security findings from the project's own audits are tracked as public issues
under the `security` label, with severity (`sev:*`) labels. linkring is a local
CLI with no network access, so open findings describe risk to the person
running it, not to a deployed service.
